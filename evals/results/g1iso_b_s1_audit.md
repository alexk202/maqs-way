# §1-аудит g1-iso-b: все 23 «хита» — FP-класс вариантных пар датасета; tail-класс = 0 (2026-10-25)

## Что случилось

Прогон g1-iso-b (per-question изоляция, amend-1 порядок): R@5 1.000 (156/156),
empty 0, mal 0, other_fail 0, trunc 0, capped 3, loop 3, facts_at_900 0,

зафиксированы артефактом, но вердикты §2/§3 по СТОП-правилу НЕ вынесены.

**§1-проверка дала вне-допуска по БУКВЕ пререга**: confirmed = 23 факта (1.58%)
в 21 вопросе из 1460 (допуск ≤5). Проверка класса хитов показала: это НЕ утечка.

## Аудит класса хитов (метод и результат)

Для каждого confirmed-хита: покытие слов факта (длиной >3, без стоп-слов)
собственным хейстаком вопроса. Порог FP-класса ≥ 0.6 (факт — легитимное
извлечение собственного разговора).

**Результат: 23/23 — FP-класс (покрытие 0.86–0.92), 0 — tail-класс.**
Ручная проверка 5 пар: тема каждого факта («language exchange», «workshop»,
«body scan meditation», «turbinado/carrot cake», «mid-century dresser»)
присутствует в собственном хейстаке вопроса; точные 5-граммы совпадают с
**пересказанными вариантами той же исходной беседы в хейстаках других вопросов**
(LongMemEval-cleaned содержит re-worded варианты одних разговоров; общих
30-граммов нет — формулировки независимы). Детектор по построению не отличает
«чужой контент через хвост» от «совпадение формулировки с вариантом той же
беседы» — это измеримый FP-пол.

**Ставка FP-пола стабильна**: часть B (per-question изоляция, 123 факта) —
2 confirmed = 1.6%; g1-iso-b (1460 фактов) — 23 = 1.58%. У q0-контроля
g1-iso-a (пустой хвост) хиты этого же класса. Истинные хвостовые утечки
(класс «virtual coffee breaks»: тема ОТСУТСТВУЕТ в собственном хейстаке)
в изолированных прогонах — 0.

## Следствия

1. **Поправленная оценка замороженного g1: 14.7%** (сырая 16.31% − FP 1.6%);
   g1-iso-a: 16.5% − 1.6% ≈ 14.9%. Хвостовые утечки — подлинные и большие,
   датированы форензикой; пол отделяется.
2. **Допуск §1 в форме счётчика не масштабируется**: одна и та же ставка 1.6%
   проходит на 12 вопросах (2 ≤ 5) и падает на 156 (23 > 5). Допуск, заданный
   до измерения пола, калиброван неверно — это методологическая ошибка
   пререга, не изоляции.
3. **Предложение amend-2 (на подпись владельцу)**: вердикт §1 сделать
   КЛАССОВЫМ, а не счётчиковым: (a) **tail-class = 0 обязателен** (факт,
   чья чужая тема отсутствует в собственном хейстаке, покрытие < 0.6 — как
   «virtual coffee breaks»); любое ненулевое значение → СТОП;
   (b) **FP-class** (покрытие ≥ 0.6 — вариантные пары) — отчёт без гейта;
   (c) авто-аудит встраивается в `g1iso_fix_check.py` (тот же топик-тест).
   По этому правилу: часть B — tail 0 ✓; g1-iso-b — tail 0 ✓; замороженный g1 —
   tail-класс подтверждён (274 raw − ~24 FP-пол ≈ 250 подлинных).
