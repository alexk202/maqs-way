## 1. Схема (канон g1; sha256 канонизирован в артефакте)

```json
{"type": "object",
 "properties": {"memory": {"type": "array", "maxItems": 40, "items": {
   "type": "object",
   "properties": {"id": {"type": "string"},
                  "text": {"type": "string", "maxLength": 900},
                  "linked_memory_ids": {"type": "array", "items": {"type": "string"}, "maxItems": 10}},
   "required": ["id", "text"]}}},
 "required": ["memory"]}
```

- Форма = ровно то, что парсит mem0 (`json.loads(...).get("memory", [])`, элемент `.get("text")`;
  примеры в ADDITIVE_EXTRACTION_PROMPT: `{"memory": [{"id": "0", "text": "…", "linked_memory_ids": […]}]}`).
- **maxItems = 40** (length-bounding, совет 24.10 §11.1): природный максимум b2 =
  39 памятей/вопрос (p90 = 17); арифметика стены: 40 фактов ≈ 7200 chars ≈ 1850 токенов —
  под стеной 2000 с запасом; экстракция 41+ фактов упёрлась бы в стену и без грамм-слоя.
- **maxLength(text) = 900**: стандарт самого промпта mem0 («15–80 слов, до 100 для
  детальных» ≈ 700 chars) + 30% запаса; блоатинга текста не ждём (B6 здесь нет).
- Пустой массив разрешён (кейс «нечего извлекать», пример 3 промпта).
- `linked_memory_ids` НЕ обязателен (по промпту: «omit or pass empty array») — обязательность
  не навязываем, использование пишем в метрику (бейзлайн для (ii)).

## 2. Конфиг и сервер

- `max_tokens=2000`, `temperature=0`, БЕЗ `prompt=` — b2 точный.
- Сервер: та же линия запуска, что probe/b4, + **`--seed 42`** (Q4 совета 24.10). Seed
  проверен smoke'ом: два идентичных запроса → идентичный md5 вывода. Значение произвольное,
  **закреплено за всей веткой** (все сравнительные прогоны — с ним). GPU-недетерминизм не
  отменён (канон prereg-v03): по-вопросные пересечения между прогонами НЕ интерпретируются,
  вердикты — только по гвардам и классам. g1-vs-b2 остаётся одноразовым-vs-одноразовым
  (b2 бежал без seed) — гварды по числам, без послаблений.
- Единицы (закрыты в b4): «вызов» = server-side completion; сверка с llama-логом после
  прогона; 0 неотаттрибуированных ожидается.
- Отмена прогона: свободная VRAM Vulkan1 < 2 ГБ на старте или повторные OOM/ошибки сервера.
