# Pre-reg-lite: второй стенд — встроенная графика Intel Arc (Vulkan0), детерминизм панели-12 (2026-10-27)

ТЗ владельца; формат prereg-lite как у реп-пенальти- и дрифт-зондов
(`c9c0dba`, `f58c4d1`): критерии записаны ДО запуска, коммит до любых
прогонов, выводы — append-only. Пререги прошлых пакетов не трогаются.
Proposal `determinism-paired-per-question.md` v0.5 — процессная рамка
(окно, канарейка режима — метка, не разрешение).

## Цель и границы

- **Стенд-2**: встроенная графика Intel Arc (Core Ultra 9 185H), устройство
  Vulkan0 в нумерации llama-server. Цель — проверить, повторяется ли выход
  побайтно ВНУТРИ этого стенда: проходы 1–2 подряд идентичны; после
  перезапуска сервера проход 3 идентичен проходам 1–2.
- **Совпадение с RTX-эталоном НЕ является критерием** — только запись факта
  (совпадения raw-выходов с доступными RTX-артефактами панели, без
  интерпретаций).
- Любое расхождение — записать как есть, без интерпретаций сверх данных.
- Владелец сам останавливает свои сервисы на Vulkan0 (:8080, :8083) и
  сообщает «Vulkan0 свободен»; агент эти сервисы не трогает и до
  подтверждения ничего не запускает.

## Шаги и критерий (заранее)

1. Владелец подтверждает «Vulkan0 свободен» (сервисы :8080/:8083 остановлены).
2. Старт llama-server на Vulkan0, :8087; проверка: модель загрузилась,
   в логе `Vulkan0 : Intel(R) Arc(tm)`, `/slots` отвечает. Модель не
   загружается или сервер падает → **СТОП, отчёт владельцу**.
3. Запуск A (`STAND2_PASSES=2`, артефакт `stand2_panel12_A.json`): канарейка
   → проход 1 → канарейка → проход 2 (подряд, один экземпляр сервера).
4. Перезапуск сервера (kill PID, свежий процесс, те же флаги) → запуск B
   (`STAND2_PASSES=1`, артефакт `stand2_panel12_B.json`): канарейка → проход 3.
5. Сравнение `stand2_compare.py`: артефакт
   `results/stand2_igpu_determinism_check.json`.
   - **КРИТЕРИЙ**: проходы 1 и 2 побайтно идентичны (raw extraction-выходы,
     stored texts, frames) по ВСЕМ 12 вопросам панели; проход 3 после
     перезапуска идентичен проходам 1–2 по тем же трём полям.
   - Критерий ВЫПОЛНЕН → внутри-стендовая побайтовая идентичность на iGPU
     подтверждена (для стабильных вопросов панели, окно данного стенда).
   - Любое расхождение → записано как есть (per-question таблица + byte-diff
     в лог), **без интерпретаций сверх данных**.
   - Совпадение с RTX (detA/detB/f500before/f500after) — только факт
     (`rtx_fact_only` в артефакте), не критерий.
   - Канарейки: отпечатки всех трёх проходов в заголовках; `all_same_fp` —
     диагностическая метка (не разрешение; правило v0.3/v0.4 без изменений).
6. Сервер с Vulkan0 выгружен (PID-адресный kill); владельцу: «Vulkan0
   свободен, сервисы можно поднимать».
7. Итог — append в `proposals/determinism-paired-per-question.md` (v0.6 или
   пометка в v0.5 — по факту), заметка `evals/results/stand2_igpu_note.md`;
   коммит, push.

## Оценка времени

~35–70 мин GPU (iGPU может быть медленнее RTX ~2×): загрузка модели ~2×3 мин,
запуск A ≈ 2×(канарейка ~2 мин + панель ~6–12 мин), запуск B ≈ 8–14 мин.
