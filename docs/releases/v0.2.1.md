## Shared-history confound — found, measured, eliminated

- **Found** by the H5 [CRIT] isolation guard (2026-10-25): no runner set
  `history_db_path`, so mem0 defaulted to a shared live history DB — every
  extraction call carried an uncontrolled tail of previous questions/runs
  (bidirectional: read into prompts, written by ingest).
- **Measured** (read-only forensics + unique-shingle classifier,
  append-only): 14.8% of the frozen g1 store's facts were genuine tail
  leaks (249/1680; g1-iso-a: 252/1684). Raw detector rates (16.3%) include
  the dataset variant-pair FP floor (~1.6%).
- **Eliminated** by per-question history isolation in ALL runners
  (`history_db_path` → temp DB per question). Tail-class leaks = 0 on the
  isolated re-runs (g1-iso-b, full-500-iso: 135 confirmed = all FP-class,
  ≈ the measured 1.6% floor; zero true leaks).
