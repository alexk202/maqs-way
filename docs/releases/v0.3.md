## extensions (machine-readable anchor; core data model untouched)

`maqs-way-standard.json` `extensions` block grew with the canonized
norms — fields: `alive`, `critical` {label, provenance}, `layer`
(persistent/session/transient, absent → unknown); policies: `alive_cap`
(per scope per subject), `overflow` (deny | evict_oldest, default deny),
`escalate_after_denials` (no default — MUST be declared),
`critical_zone_fraction` (0.15, owner E11), `counters` (I10/I11/I12
declared triples + `work_sink`), `i14_handler_registry`, `i15_layers`,
`audit_procedure` (p9_one_sided, p10_read_only), `pipeline_hygiene`
(dead-code rule; baselines with tolerance 0.10 ±10%),
`b4_write_atomicity`, `run_determinism`. Logging events:
`e10_e11_events` (cap_overflow, eviction), `i10_i11_i12_events`
(warning_aggregated, halt_alert, escalated). `verification_suite.metrics`
+= alive_cap_overflow_rate (P8, advisory), unlabeled_ratio (reported,
not gated), E11.verify_placement. Lifecycle states and the data model
were NOT extended (the B4 in-progress marker is a mechanism-internal
state, stated in canon).

## Pipeline hygiene — found, fixed, gated

- **Found** (2026-10-27, scope annotation 1634367): `check_pipeline_hygiene`
  was RED on tags v0.2 and v0.2.1 — `check_release.py` undeclared
  standalone (dead code by the 0.5a rule) + 0.6a baseline drift (10→13
  check scripts, 7→9 proposals since the 1.7b snapshot e1ff492). The
  gate was not part of `maqs_way_audit all` and not run by the release
  gate, so it went unnoticed.
- **Fixed** (89a955c, the drift-explaining commit): `check_release.py`
  declared standalone (self-point + integration docstring); baseline
  refreshed with the drift explained BY NAME (scripts: check_release
  319c5e1, check_scoreboard 4926756, check_name_policy 4b3528d;
  proposals: determinism-paired-per-question af0654f,
  p4-mem0-behavioral-isolation 948c62c).
- **Gated**: NEW executable check G6 in `check_release.py` — runs ALL
  `schemas/check_*.py` (except itself), criterion = exit code, RED with
  the gate name, no silent skips; a red gate can no longer slip into a
  release unnoticed. Negative test: a broken fixture turns the release
  RED with the gate named (verified on a temp branch, not pushed).
